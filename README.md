## 🚀 Featured Projects

### 🎓 EduRAG — Multimodal AI Study Assistant
An end-to-end Retrieval-Augmented Generation (RAG) system for EdTech. Students upload study materials (PDF, image, or audio) and get AI-generated answers with source citations.
- **Stack:** Python, FastAPI, Next.js, PostgreSQL, ChromaDB, Gemini LLM, Sentence-Transformers
- **Repo:** [github.com/SifatpHero1/edurag](https://github.com/SifatpHero1/edurag)

### 📊 ShipNow — Logistics & Invoices Dashboard
A feature-rich logistics and invoice management dashboard with real-time financial metrics, status filtering, multi-select invoices, and instant search — built with a modern component architecture.
- **Stack:** Next.js, TypeScript, Tailwind CSS, Lucide React
- **Repo:** [github.com/SifatpHero1/shipnow-dashboard](https://github.com/SifatpHero1/shipnow-dashboard)

### 🌿 Plant Disease Prediction with AI
An AI web app that detects plant diseases from leaf images using a Keras CNN model, served through a FastAPI backend with a Next.js frontend.
- **Stack:** Python, TensorFlow/Keras, FastAPI, Next.js
- **Repo:** [github.com/SifatpHero1/Plant-diseases-prediction-with-AI](https://github.com/SifatpHero1/Plant-diseases-prediction-with-AI)
